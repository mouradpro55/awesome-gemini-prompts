# رحلة الواحات (The Oasis Journey)

هذا هو مجلد مشروع لعبة "رحلة الواحات" باستخدام محرك Godot 4.

## هيكل المجلدات

- `scenes/`: يحتوي على المشاهد (Screens, UI, Game World).
- `scripts/`: يحتوي على ملفات الكود البرمجي `GDScript`.
- `assets/`: يحتوي على الموارد (صور، صوتيات، خطوط).
- `data/`: يحتوي على بيانات اللعبة (مثل الألغاز بصيغة JSON).

## كيفية تشغيل المشروع

1. قم بتحميل Godot Engine 4.
2. افتح المحرك واختر Import (استيراد).
3. اختر الملف `project.godot` الموجود في هذا المجلد.
